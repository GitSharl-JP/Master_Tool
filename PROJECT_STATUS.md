# Project Status

## Current state
Local, fonctionnel, pour **une ou deux personnes** (responsable, relecteur facultatif et échéance par contenu ; aucune validation à deux obligatoire). Parcours testé de bout en bout (`tests/parcours.mjs` : 429 contrôles, ~160 s dont étape navigateur ; à lancer depuis PowerShell/un terminal Windows normal, pas depuis un shell sandboxé : Edge n'y écrit pas ses PNG).
